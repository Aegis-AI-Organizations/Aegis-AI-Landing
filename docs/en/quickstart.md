# 🚀 Quickstart: Landing Page

The Aegis landing page is a **Next.js** static site (SSG). It is the public
marketing and trust entry point, fully decoupled from the authenticated
Dashboard.

---

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

The output is static and can be served from any CDN or edge host.

## Boundary reminder

The landing page must not share Dashboard cookies, JWTs, deployment tokens, or
internal API credentials. Any transition into the product happens through the
Dashboard login or onboarding flow.
